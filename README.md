# TD2 - Algorithmes évolutionnaires

Deux exercices basés sur la feuille de TD et le cours d'Heuristiques & Métaheuristiques.

## Exercice 2 - Transport
- Branch and Bound simplifié
- Recherche taboue
- Résultat : D1 = (3, 5, 0), D2 = (1, 0, 8), coût = 52

## Exercice 3 - Voyageur de commerce
- Recherche taboue (voisinage 2-opt)
- Recuit simulé avec 5 itérations et températures 10, 8, 6, 4, 2
- Algorithme génétique (sélection, croisement, mutation)
- Circuit initial : 1-2-3-4-5-6-7-8-1, coût = 103
- Les trois méthodes donnent un meilleur coût de 98 avec les paramètres fixés dans les scripts.
